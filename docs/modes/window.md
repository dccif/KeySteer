# Window：用键盘整理整个工作区

按模式分步学习与观看视频，请从[窗口管理总览](/window-management/)开始。

把浏览器放到左边、编辑器放到右边，把零散窗口收成标签组，再保存常用布局。Window 让你从移动一个窗口开始，逐步搭建自己的工作区。

::: tip 先试一次移动
把鼠标放到一个普通窗口上 → 按 `Alt+W` → 松开入口键 → 按 `H/J/K/L` 移动 → 按 `Q` 结束。

本页使用发布默认键位。`Alt+W` 在 Windows 上是 Alt，在 macOS 上是 Option，**不是 Command+W**。`Primary` 则默认是 Windows 左 Alt / macOS Command。按键字母大写仅便于阅读；只有写出 `Shift+` 时才需要 Shift。
:::

## 先选你要做的事

| 你想做什么 | 从 Window 按 | 接下来 |
| --- | --- | --- |
| 移动、缩放、居中或跨屏 | 留在 Window | 方向键调整，`S` 切换缩放 |
| 把一个窗口放到半屏或角落 | `A` → Quick | 按方向选择位置和比例 |
| 把多个窗口排好并微调分区 | `E` → Editor | 自动排列，再调整区域 |
| 把窗口收成可切换的标签组 | `T` → Tabs | 自动整理同应用窗口，也可手动组合 |
| 恢复保存的布局或标签模板 | `R` → Restore | 输入列表编号 |

Quick、Editor、Tabs、Restore 中按 `Q` 返回 Window，再按 `Q` 回到待机。`Primary+Q` 可直接回到待机。退出保留已经生效的调整；要回退请使用撤销。

## 移动与选择窗口

进入时会激活并锁定鼠标下的窗口。之后鼠标移开，也不会自动换目标。屏幕上的数字表示窗口编号，输入编号即可激活目标并把鼠标移到它的中心。

| 按键 | Window 中的操作 |
| --- | --- |
| `H / J / K / L` | 向左 / 下 / 上 / 右移动；按住可连续调整 |
| `S` | 在移动与中心缩放之间切换 |
| `C` | 居中 |
| `D` | 移到下一块显示器 |
| `F` | 最大化 → 最小化 → 还原，循环切换 |
| 数字 | 按编号选择窗口 |
| `Tab / Shift+Tab` | 下一个 / 上一个窗口；在标签组内优先循环成员 |
| `X` | 请求关闭当前窗口；应用可能显示保存确认 |
| `Z / Shift+Z` | 撤销 / 重做窗口调整 |
| `Shift+C` | 恢复本次窗口会话初始的位置、尺寸及窗口状态 |

默认只列出**当前屏幕、非最小化**的候选窗口。已有编号尽量保持稳定，关闭窗口不会把其余窗口重新编号；重新进入时可能回收空缺编号。只有可能组成更长编号的前缀才等待，默认 250 ms。

需要点击一下应用？按住 `Primary` 临时使用 Normal 的鼠标移动、滚动和点击绑定，松开后继续调整原目标。Window 各模式的方向键独立配置，修改 Normal 的方向键不会自动修改这里的键位。

## 场景一：浏览器与编辑器并排

1. 鼠标放到浏览器上，按 `Alt+W`，松开入口键后按 `A` 进入 Quick。
2. 按 `H`，把浏览器放到左半屏。
3. 输入编辑器的窗口编号，再按 `L`，把它放到右半屏。
4. 按 `Q` 返回 Window，再按 `Q` 开始工作。

Quick 每个轴独立调整：第一次方向输入从最接近半屏的比例开始，同方向继续按会缩小，反方向会扩大。例如左半屏后按 `K`，可进一步放到左上区域。默认比例有 `1/4、1/3、1/2、2/3、3/4`，以及自动加入的满屏比例。需要回退时按 `Z`。

## 场景二：自动排列，再给主窗口多一点空间

按 `Alt+W` 后按 `E` 进入 Editor，**会立即尝试自动排列候选窗口**。布局受应用最小尺寸约束，不必按 Enter 应用。

| 按键 | Editor 中的操作 |
| --- | --- |
| `H / J / K / L` | 选择左 / 下 / 上 / 右的区域 |
| `Shift+H/J/K/L` | 朝指定方向切分区域 |
| `Ctrl+H / Ctrl+L` | 缩小 / 增大选中区域宽度 |
| `Ctrl+K / Ctrl+J` | 缩小 / 增大选中区域高度 |
| 两个窗口编号 | 依次选择并交换两个窗口的位置 |
| 反引号（&#96;）后输入区域编号 | 选择区域；已有源窗口时可移入空区域 |
| `X` | 删除区域，不关闭应用窗口 |
| `Z / Shift+Z` | 撤销 / 重做编辑 |
| `Ctrl+S` | 保存布局 |

例如，先用方向键选中编辑器所在区域，再按 `Ctrl+L` 增大它的宽度。相邻区域会联动调整，保持平铺。如果应用的最小尺寸不允许继续调整，查看屏幕提示，尝试别的区域或减少分区。`Z` 可逐步撤销，包括进入 Editor 时的自动排列。

## 场景三：把零散窗口收成标签组

从 Window 按 `T`，会先把同一应用的兼容、未分组窗口按屏幕分别整理成组，并保留已有组。想撤销这次自动整理，按 `Z`。

你也可以组合不同应用的窗口：

1. 根据屏幕编号选择第一个窗口，例如输入 `1`，再按空格结束编号。
2. 输入第二个窗口的编号，例如 `2`，再按空格，立即组成一组。
3. 继续输入编号可追加成员，按 `T` 结束这一组，准备下一组。
4. 按 `Q` 返回 Window。退出模式后标签组仍保留，可用鼠标点击标签切换。

这里的 `1`、`2` 是示例，请使用实际编号。空格用于明确编号边界，避免把窗口 1 和 2 误读成窗口 12。

| 按键 | Tabs 中的操作 |
| --- | --- |
| `Tab / Shift+Tab` 或 `J / K` | 下一个 / 上一个标签 |
| `H / L` | 把活动标签向左 / 向右排序 |
| `~` 后输入组编号 | 选择整组；例如 `~1` |
| `D` | 把活动成员移出组 |
| `X` | 解散当前组，不关闭应用 |
| `Z / Shift+Z` | 撤销 / 重做分组和排序 |
| `Ctrl+S` | 保存标签模板 |

每组只显示活动成员，Quick 和 Editor 将整组视为一个布局目标。最小化活动成员会收起整组；解散或正常退出 KeySteer 会恢复本程序收起的成员。分组保留到解散或退出 KeySteer，跨次使用请保存模板。

Windows 上退出模式后还可以拖动标签排序、拖到另一组转移窗口，或拖动 `~组编号` 合并整组；标签多时可滚动标签栏。macOS 通过系统最小化和恢复切换成员，可能出现系统动画。原生全屏或不兼容的窗口会显示不支持的提示。

## 保存与恢复常用工作区

在 Editor 或 Tabs 按 `Ctrl+S`，在底部输入备注并按 Enter 保存；备注可留空，最多 80 个字符。例如命名为“写代码”或“阅读与笔记”。

从 Window 按 `R` 打开统一预设列表，输入编号恢复；`PageUp / PageDown` 翻页，每页六项。

| 保存类型 | 恢复时会发生什么 |
| --- | --- |
| Layout 布局 | 用当前窗口填入保存的区域；成功后默认进入 Editor，继续微调 |
| Tabs 标签模板 | 进入 Tabs，依次选择所需窗口，选满后自动应用；选满前可取消 |

**模板不保存应用身份，也不会启动应用或重新打开文档。** 布局恢复使用当前窗口的最近活动顺序，多余窗口保持原位，窗口不足时保留空区域。标签模板由你重新指定成员。

要删除预设，在 Restore 按 `X` 切到删除状态，输入编号核对名称，再按 `Enter` 删除。再按 `X` 回到恢复状态。删除模板不影响已经运行的标签组。

布局和标签模板共用 `workspace.ksw`：Windows 便携版在程序目录，macOS `.app` 在 `~/Library/Application Support/KeySteer/`。可通过[配置与模拟器](/editor/)导入、练习和导出；网页只改变示例窗口与浏览器存储。将导出的文件替换到程序数据目录，再打开 Restore 读取；替换前可先备份原文件。

## 顺手调整音量和输出设备

以下默认组合键在 Window、Quick 和 Editor 中可用。按住 `V` 再按对应键；系统操作额外按住 `Shift`。

| 操作范围 | 降低 / 提高音量 | 静音切换 | 上一个 / 下一个输出设备 |
| --- | --- | --- | --- |
| 当前目标窗口所属应用 | `V+J / V+K` | `V+M` | `V+H / V+L` |
| 系统 | `Shift+V+J / Shift+V+K` | `Shift+V+M` | `Shift+V+H / Shift+V+L` |

音量每次变化 1%；提高音量不会自动解除应用静音。同一应用的多个窗口可能共享音频会话。

- **Windows**：应用音量需要可用音频会话；没有会话时先让应用播放声音。切换设备后是否立即迁移当前声音取决于应用。
- **macOS**：系统音频支持 macOS 14+；应用独立音频需要 macOS 14.2+ 和系统音频录制权限，本地处理会增加音频延迟。某些输出设备不支持软件音量调节。

## 遇到问题时

| 现象 | 可以怎么做 |
| --- | --- |
| 没有看到目标窗口编号 | 确认当前屏幕、最小化状态和窗口兼容性；多屏与最小化候选可在各模式配置中调整 |
| 调整后退出，没有恢复原位 | 退出保留布局；使用 `Z` 撤销，或在 Window/Quick/Editor 用 `Shift+C` 恢复本次会话初始状态 |
| `X` 的效果和预期不同 | Window 关闭窗口，Editor 删除区域，Tabs 解散组，Restore 切换删除状态；先看当前模式提示 |
| 升级后新快捷键没有反应 | 显式 `[模式.bindings]` 会替换该模式默认表；对照最新默认配置补入新绑定 |
