# 模式与生命周期

Mode/Plugin 是平台无关状态机：接收 `ModeEvent` 和 `HostContext`，返回 `CommandBatch`，经 Presenter 提交视图。不能直接调用原生 API、读配置或依赖具体 renderer。

## 代码入口

| 能力 | 位置 |
| --- | --- |
| 空闲、连续移动与滚动 | `src/modes/idle.rs`、`src/modes/normal.rs` |
| 网格与共享定位状态 | `src/modes/grid.rs`、`src/modes/targeting.rs` |
| Hint 标签、搜索、扫描会话 | `src/modes/hint/` |
| 窗口模式、编辑、分组与恢复 | `src/modes/window.rs`、`src/modes/window/` |
| 临时文本透传 | `src/modes/text_input.rs` |
| 插件 | `src/plugins/builtin/` |
| 注册与生命周期词汇 | `src/app/mode_catalog.rs`、`src/api/lifecycle.rs` |

普通网格与递归网格共用 `GridMode` 的事件、命令和生命周期实现，保留各自的视图、样式和模式身份。catalog 直接装配 `TargetingController` 与样式；几何选择仍由控制器负责，Normal 的静默定位也复用该控制器。

Normal 移动与滚动共用原生显示帧时钟，各自维护手势状态并输出独立命令：按下立即执行短步，随后按帧的实际经过时间持续更新，不等待键盘重复延迟；仅在最后一个移动／滚动手势释放后停止时钟。普通滚动使用配置预编译且独立于短按距离的每秒速度，叠加当前速度倍率并保留小数余量；帧到达后忽略 OS 重复，没有显示帧时保留键盘重复回退。连续滚动输出可取消的 `ScrollFrame`，短按保留 `Scroll`；移动按下／释放不取消滚动帧，滚动自身状态改变且已发出连续帧时才作废旧帧；短按和页滚动不取消不存在的帧，页滚动也不重算连续滚动速度，原生执行策略见[平台后端](06-platform-backends.md)。半页／整页动作和普通滚动的仅短按配置不启动滚动帧时钟，也不接受重复滚动。模式借用仍按原 owner 接收帧与释放，会话清理清空全部保持状态。

## 关键约束

- targeting `keep` 保留同一实例及选择状态；只有 `restart` 发 `Restarted`。
- Finish 应幂等，点击后的生命周期动作不得递归触发点击。
- modal Pop 恢复下层状态，不把恢复当成重新激活。
- Idle 不捕获普通输入；其他模式的输入兴趣通过 API 声明，Engine 不硬编码模式内部键表。
- 会话结束取消其异步工作并隔离迟到结果；持久窗口分组与当前模式会话的寿命分开。
- Hint 已输入前缀时，迟到扫描结果不能重新分配正在使用的键码。
- Hint 搜索可在首批结果到达前打开；空结果重试保留输入与搜索框，后续结果继续按当前查询过滤。

搜索编辑使用 `api/text_edit.rs` 的 Unicode 光标／选区操作，复用会话查询缓冲。修改文字时过滤，移动光标只重绘。复制信息槽成功后退出搜索，复制输入选区保留编辑。

搜索 accept 恢复全部标签并留在 UIHint，唯一结果或有多项选择时移动鼠标到当前检查点（未调整时为集合中心），不触发 FinishMode；cancel 不移动。搜索过滤不能修改完整标签的编号容量／游标，迟到扫描更新继续使用完整计划。普通词混合匹配标签／文字／简拼，`@label` 项仅精确匹配标签，空格项仍按输入顺序合并去重。

单独输入 `@` 保留候选标签显示，不代表全选；输入 `@l` 按标签前缀缩小范围，完整 `@la` 对应唯一标签。空格后的 `@` 同样显示下一项候选，已选项及复制顺序保持不变。

`@` 也可后置：`ld@` 与 `@ld` 等价，只匹配标签。普通搜索词后追加 `@` 即可切换到标签匹配，删除标记则恢复混合搜索；多选可混用，如 `ld@ @ka`。

OCR 预览与复制共用流式空白清理：去除汉字间和中文标点周围的识别空格，其他连续水平空白压为单空格，保留英文词边界与换行；不改动原始扫描数据及辅助功能字段，不构建中间字符串。

Window 的应用及系统音频动作保留上次反馈，直到异步结果替换；音量连发、静音与输出设备切换不先提交空白提示，重复相同结果不重绘。其他操作仍按原有规则清除旧反馈。

Window 多选状态与输入位于 `window/multi_selection.rs`，按窗口身份保存最初目标与选择集合；第一段逐位立即切换，空格后的完整编号仅在下一空格或确认时切换；操作键自动确认并继续执行原操作。输入复用 `api/text_edit.rs` 的光标／选区，在任意位置插入和删除；选择集合始终按完整输入从进入时快照重算，前台预览跟随光标前的编号。`WindowOperation::Activate` 激活预览但不移动鼠标、不替换 worker 会话目标；确认回传预览窗口几何和 Tab 状态，模式仍保留最初多选身份。显式清空恢复最初窗口；Window 与 Editor／Tab 交接保留选择，Quick／Restore 进入和离开均丢弃多选及输入，并先恢复最初窗口的焦点。Quick 继续遵循现有 `target` 配置与会话目标交接逻辑。帮助面板仅显示简短状态、输入光标及配置映射，不附示例。选中 tab 成员代表整个组，几何操作每组只提交一次。移动、缩放、状态、关闭和音频使用同一选择集合；Editor 有多选时仅以选中组建立自动平铺事务，未多选时仍使用全局候选。

Window 入口沿用 `Settings.target` → `WindowOperation::AcquireFrom`／`Retarget` → `WindowTarget::with_fallback` 的现有链路：`active`／`mouse` 决定来源优先级，仅来源缺失或最小化时尝试另一来源，查询／激活错误不重定向。未配置 target 时，首次进入仍使用 `Acquire(ctx.cursor)`，模式间交接保留现有会话目标。macOS 的 AX 取点补救只实现 mouse 来源的窗口识别，不能自行改变入口优先级、切换到 active 或重建会话。

输入全部删除或 Esc 撤销后恢复本轮输入前的选择快照，并用 `WindowOperation::Activate` 恢复最初窗口的原生焦点；显式清空、结束、退出或重启会话也恢复该焦点。清除退出先等待激活请求的异步确认，再继续切换或重启，避免会话取消抢先丢弃恢复请求；最初窗口已关闭时直接完成清理。连续空输入不重复激活，不重新解析 active/mouse，不额外移动鼠标。

多个逻辑窗口选中时，鼠标跟随已确认窗口中心的等权平均点；选择变化和几何确认更新该点，不叠加各窗口结果的相对鼠标偏移。Tab 组只贡献一个中心，最小化窗口不参与。初始进入及单个逻辑窗口保留原有鼠标跟随语义，不使用预测几何定位。

Tab 入口优先使用显式多选，发送 `TabOperation::EnterSelection` 而非自动按应用组合；后端先解析并验证全部所选身份，将已分组成员扩展为整组，再以单次可撤销事务合并。空选择或失效选择不得回退到自动组合；未多选时沿用 `Enter`。

UIHint 搜索输入期间，按匹配程度和配置类别优先级自动显示首项，point_next 从当前结果继续循环预览，面板只显示当前预览目标，不把歧义候选加入已解析多选。预览不移动原生鼠标，accept 才移动到当前检查点；编辑查询清除手动预览，光标／选区变化保留。手动预览独立保留 label／几何身份，追加／退休扫描后重新定位候选索引，保留仍匹配的目标；退休后清除失效手动预览并显示当前最佳匹配；自动预览随新结果重新选择首项。空查询、单独 @ 与无结果不产生面板。

搜索预览与点位调整复用 `hint::next_target_position` 推进循环索引：未选中时取首项，末项回绕。各自保留候选顺序及更新动作；预览更新焦点，调整更新检查点。

UIHint 在结果信息面板出现时按需创建点位检查状态。完整标签代码优先，文字／简拼仅在唯一命中时选中；未完成、无效和歧义项不计入 Point 总数。确定标签按查询顺序去重，以普通跳转坐标的等权平均作为初始点，调整期间通过 point_next（默认 Tab）依次切换，末项回到首项。OCR／辅助功能默认按选择顺序拼接，坐标／颜色跟随当前点；field_modes 四项均可独立切换 concat／switch。单点和已确定的多点均显示颜色栏并启动后台取样；颜色 concat 按选择顺序逐点采集并缓存，保持一个在途请求，全部完成后执行待定复制，失败的成员保留空位。关闭面板取消采样，迟到结果不恢复颜色。

轻触切换输入／调整；调整时隐藏文字光标，以右侧圆点和可选的多点计数提示状态，切回恢复查询及选区。移动复用 Normal 状态机和原生帧时钟，只改变检查点，接受搜索才移动原生指针。点击等操作先接受当前点并退出搜索，再沿原操作路径执行；调整中复制信息成功也接受当前点，失败保留调整。单点文字按全部扫描目标中的最小包含矩形命中，空白处清除旧文字。每次移动取样带递增版本；定时刷新不叠加在途请求，颜色复制复用当前样本或等待当前请求，失败不复制旧颜色。帧和回调不重建成员集合。选择集合改变立即请求新样本，但复用已运行的刷新计时器；仅进入／离开检查状态时启停计时器，关闭面板仍显式清理。原生调整状态只在可用性或调整状态变化时更新；切换查询时仍停止正在进行的点位移动。
