# 模式与生命周期

Mode/Plugin 是平台无关状态机：接收 `ModeEvent` 和 `HostContext`，返回 `CommandBatch`，经 Presenter 提交视图。不能直接调用原生 API、读配置或依赖具体 renderer。

## 代码入口

| 能力 | 位置 |
| --- | --- |
| 空闲、连续移动与滚动 | `src/modes/idle.rs`、`src/modes/normal.rs` |
| 网格与共享定位状态 | `src/modes/grid/mod.rs`、`src/modes/targeting.rs` |
| Hint 标签、搜索、扫描会话 | `src/modes/hint/` |
| 窗口模式、编辑、分组与恢复 | `src/modes/window/mod.rs`、`src/modes/window/` |
| 快速模式切换 | `src/modes/quick_switch.rs` |
| 临时文本透传 | `src/modes/text_input.rs` |
| 插件 | `src/plugins/` |
| 注册与生命周期词汇 | `src/app/mode_catalog.rs`、`src/api/lifecycle.rs` |

`built_in_factories` 共用一份启用条件、构造函数和路由编译函数清单；条目只保存布尔值与函数指针，迭代前不构造实例或复制绑定。基础路由由 `compile_route` 处理，应用覆盖在基础编译成功后才复制；窗口和插件也复用 `compile_app_route`，UIHint 单独处理其覆盖类型。生产入口 `built_in_specs` 按顺序构造实例并编译路由，首个错误立即返回；兼容测试入口 `built_in` 只调用构造函数，不因无关的路由配置错误失败。两种历史顺序用普通数组与共享数组拼接，仅在兼容入口把 Text Select 延至共享数组之后，不排序；禁用条目先过滤，再调用构造或编译函数。完整性测试检查两者的身份集合、启用开关和各自的顺序。窗口族按各自 `WindowKind` 读取配置与启用开关，路由按模式 ID 配对，避免并行数组顺序造成错配。新增模式步骤见[配置维护入口](03-configuration.md#新增模式的维护入口)。

普通网格、递归网格与 Bisect 二分定位共用泛型 `GridMode<G>` 的事件、命令和生命周期源码；catalog 分别装配 `GridGeometry`、`RecursiveGeometry`、`BisectGeometry`，各自绑定具体样式、视图和模式身份。`targeting/geometry.rs` 定义三种几何，`grid/variants.rs` 将几何和样式静态配对；`TargetingController<G>` 的选择、终态、重置和跨屏重放在编译时分别实例化，不保存模式种类标记或样式枚举。Bisect 不存字母布局；Grid 不存递归最小尺寸。Normal 的静默定位同样在 catalog 选择具体字母几何，普通 Normal 保持原实现。 catalog 通过共享布局函数和 `From<&GridLayer>` 转换组装网格，配置到运行设置的转换仍留在装配层，模式不依赖配置类型。Bisect 通过独立 `bisect_left/down/up/right` 绑定选择半区，无标签字母表与层布局；每次只缩小一个轴，该轴到最小尺寸时仍可切分另一轴。深度上限或两轴均无法继续时沿用网格完成语义，路径记录方向供撤销和跨屏重放。无字母视图复用递归网格的区域填充、描边与终态背景，原生覆盖层资源策略不变；Window 借用定位也将 Bisect 视为网格，保留窗口会话。

三种网格的 `area_hint`／`area_text` 使用同一模态入栈命令将当前区域传给 UIHint 或 Text Select；`modes/scan_region.rs` 共用范围解析与模态返回。网格会话保持挂起，取消时扫描模式出栈并恢复进入前的层级、路径和区域；区域 UIHint 标签界面的 `previous_level` 和默认 Tab 的 `reopen_selection` 都直接出栈，即使扫描尚无结果或已输入标签。搜索输入框保持原有编辑与预览按键，先关闭搜索才能使用这些返回键。普通 UIHint 保持原有返回与 Tab 语义。UIHint 的完成／点击和 Text Select 的复制后配置仍然生效，设为 `return` 会恢复网格。区域仅属于本次扫描会话，退出后普通进入不继承它；目标模式未启用时不挂起网格。

Normal 移动与滚动共用原生显示帧时钟，各自维护手势状态并输出独立命令：按下立即执行短步，随后按帧的实际经过时间持续更新，不等待键盘重复延迟；仅在最后一个移动／滚动手势释放后停止时钟。普通滚动使用配置预编译且独立于短按距离的每秒速度，叠加当前速度倍率并保留小数余量；帧到达后忽略 OS 重复，没有显示帧时保留键盘重复回退。连续滚动输出可取消的 `ScrollFrame`，短按保留 `Scroll`；移动按下／释放不取消滚动帧，滚动自身状态改变且已发出连续帧时才作废旧帧；短按和页滚动不取消不存在的帧，页滚动也不重算连续滚动速度，原生执行策略见[平台后端](06-platform-backends.md)。半页／整页动作和普通滚动的仅短按配置不启动滚动帧时钟，也不接受重复滚动。模式借用仍按原 owner 接收帧与释放，会话清理清空全部保持状态。

移动与滚动均以按键和动作保存保持身份；同键序列中的多个移动方向不会互相覆盖。多个按键、斜向移动、横纵滚动可以叠加，反向移动按原有方向合成规则抵消；释放只移除对应动作，不停止仍被其他动作使用的共享时钟。原生暂停只停止帧投递并清除待交付帧，资源保留到后端退出。

## 关键约束

- targeting `keep` 保留同一实例及选择状态；只有 `restart` 发 `Restarted`。
- Finish 应幂等，点击后的生命周期动作不得递归触发点击。
- modal Pop 恢复下层状态，不把恢复当成重新激活。
- Idle 不捕获普通输入；其他模式的输入兴趣通过 API 声明，Engine 不硬编码模式内部键表。
- 会话结束取消其异步工作并隔离迟到结果；持久窗口分组与当前模式会话的寿命分开。
- Hint 已输入前缀时，迟到扫描结果不能重新分配正在使用的键码。
- Hint 搜索可在首批结果到达前打开；空结果重试保留输入与搜索框，后续结果继续按当前查询过滤。

搜索编辑使用 `api/text_edit.rs` 的 Unicode 光标／选区操作，复用会话查询缓冲。修改文字时过滤，移动光标只重绘。复制信息槽成功后退出搜索，复制输入选区保留编辑。

搜索 accept 恢复全部标签并留在 UIHint，唯一结果或有多项选择时移动鼠标到当前检查点（未调整时为集合中心），不触发 FinishMode；cancel 不移动。搜索过滤不能修改完整标签的编号容量／游标，迟到扫描更新继续使用完整计划。普通词混合匹配标签／文字／简拼，`@label` 项仅精确匹配标签，空格项仍按输入顺序合并去重。

单独输入 `@` 保留候选标签显示，不代表全选；输入 `@l` 按标签前缀缩小范围，完整 `@la` 对应唯一标签。空格后的 `@` 同样显示下一项候选，已选项及复制顺序保持不变。

`@` 也可后置：`ld@` 与 `@ld` 等价，只匹配标签。普通搜索词后追加 `@` 即可切换到标签匹配，删除标记则恢复混合搜索；多选可混用，如 `ld@ @ka`。

OCR 预览与复制共用流式空白清理：去除汉字间和中文标点周围的识别空格，其他连续水平空白压为单空格，保留英文词边界与换行；不改动原始扫描数据及辅助功能字段，不构建中间字符串。

Window 的应用及系统音频动作保留上次反馈，直到异步结果替换；音量连发、静音与输出设备切换不先提交空白提示，重复相同结果不重绘。其他操作仍按原有规则清除旧反馈。

Window 多选状态与输入位于 `window/multi_selection.rs`，按窗口身份保存最初目标与选择集合；第一段逐位立即切换，空格后的完整编号仅在下一空格或确认时切换；操作键自动确认并继续执行原操作。输入复用 `api/text_edit.rs` 的光标／选区，在任意位置插入和删除；选择集合始终按完整输入从进入时快照重算，前台预览跟随光标前的编号。`WindowOperation::Activate` 激活预览但不移动鼠标、不替换 worker 会话目标；确认回传预览窗口几何和 Tab 状态，模式仍保留最初多选身份。显式清空恢复最初窗口；Window 与 Editor／Tab 交接保留选择，Quick／Restore 进入和离开均丢弃多选及输入，并先恢复最初窗口的焦点。Quick 继续遵循现有 `target` 配置与会话目标交接逻辑。帮助面板仅显示简短状态、输入光标及配置映射，不附示例。选中 tab 成员代表整个组，几何操作每组只提交一次。移动、缩放、状态、关闭和音频使用同一选择集合；Editor 有多选时仅以选中组建立自动平铺事务，未多选时仍使用全局候选。

Window 入口沿用 `Settings.target` → `WindowOperation::AcquireFrom`／`Retarget` → `WindowTarget::with_fallback` 的现有链路：`active`／`mouse` 决定来源优先级，仅来源缺失或最小化时尝试另一来源，查询／激活错误不重定向。未配置 target 时，首次进入仍使用 `Acquire(ctx.cursor)`，模式间交接保留现有会话目标。macOS 的 AX 取点补救只实现 mouse 来源的窗口识别，不能自行改变入口优先级、切换到 active 或重建会话。

输入全部删除或 Esc 撤销后恢复本轮输入前的选择快照，并用 `WindowOperation::Activate` 恢复最初窗口的原生焦点；显式清空、结束、退出或重启会话也恢复该焦点。清除退出先等待激活请求的异步确认，再继续切换或重启，避免会话取消抢先丢弃恢复请求；最初窗口已关闭时直接完成清理。连续空输入不重复激活，不重新解析 active/mouse，不额外移动鼠标。

多个逻辑窗口选中时，鼠标跟随已确认窗口中心的等权平均点；选择变化和几何确认更新该点，不叠加各窗口结果的相对鼠标偏移。Tab 组只贡献一个中心，最小化窗口不参与。初始进入及单个逻辑窗口保留原有鼠标跟随语义，不使用预测几何定位。

Tab 入口优先使用显式多选，发送 `TabOperation::EnterSelection` 而非自动按应用组合；后端先解析并验证全部所选身份，将已分组成员扩展为整组，再以单次可撤销事务合并。空选择或失效选择不得回退到自动组合；未多选时沿用 `Enter`。

UIHint 搜索输入期间，按匹配程度和配置类别优先级自动显示首项，point_next 从当前结果继续循环预览，面板只显示当前预览目标，不把歧义候选加入已解析多选。预览不移动原生鼠标，accept 才移动到当前检查点；编辑查询清除手动预览，光标／选区变化保留。手动预览独立保留 label／几何身份，追加／退休扫描后重新定位候选索引，保留仍匹配的目标；退休后清除失效手动预览并显示当前最佳匹配；自动预览随新结果重新选择首项。空查询、单独 @ 与无结果不产生面板。

搜索预览与点位调整复用 `hint::next_target_position` 推进循环索引：未选中时取首项，末项回绕。各自保留候选顺序及更新动作；预览更新焦点，调整更新检查点。

UIHint 在结果信息面板出现时按需创建点位检查状态。完整标签代码优先，文字／简拼仅在唯一命中时选中；未完成、无效和歧义项不计入 Point 总数。确定标签按查询顺序去重，以普通跳转坐标的等权平均作为初始点，调整期间通过 point_next（默认 Tab）依次切换，末项回到首项。OCR／辅助功能默认按选择顺序拼接，坐标／颜色跟随当前点；field_modes 四项均可独立切换 concat／switch。单点和已确定的多点均显示颜色栏并启动后台取样；颜色 concat 按选择顺序逐点采集并缓存，保持一个在途请求，全部完成后执行待定复制，失败的成员保留空位。关闭面板取消采样，迟到结果不恢复颜色。

轻触切换输入／调整；调整时隐藏文字光标，以右侧圆点和可选的多点计数提示状态，切回恢复查询及选区。移动复用 Normal 状态机和原生帧时钟，只改变检查点，接受搜索才移动原生指针。点击等操作先接受当前点并退出搜索，再沿原操作路径执行；调整中复制信息成功也接受当前点，失败保留调整。单点文字按全部扫描目标中的最小包含矩形命中，空白处清除旧文字。每次移动取样带递增版本；定时刷新不叠加在途请求，颜色复制复用当前样本或等待当前请求，失败不复制旧颜色。帧和回调不重建成员集合。选择集合改变立即请求新样本，但复用已运行的刷新计时器；仅进入／离开检查状态时启停计时器，关闭面板仍显式清理。原生调整状态只在可用性或调整状态变化时更新；切换查询时仍停止正在进行的点位移动。

快速切换是 `modes/quick_switch.rs` 中注册的普通模式，使用普通生命周期、按键绑定和 Presenter；`app/runtime/quick_switch.rs` 只检测长按进入并抑制原手势接管后的重复。短按与原绑定 Down／Up 配对保留；未达到长按期限的其他按键取消进入，松开触发键不退出已进入的模式。默认 Esc／再次按 Q 的 `cancel_selection` 返回前一模式，Backspace 的 `previous_level` 删除前缀，均由 `quick_switch.bindings` 配置。

进入时通过 `RequestModeList`／`ModeList` 取得按使用次数及 id 排序的注册模式快照，排除自身、前一模式、上下文插件和黑名单，不限制九项。每行直接拥有目标 ModeId 和标签，绘制借用 ModeId 的名称；不另保留平行候选数组或一份名称快照，匹配标签后直接取得该行目标。与 UIHint 共用 `api/hint.rs` 的无前缀冲突标签生成与匹配；筛选不重新编号，死前缀只丢弃最后一字。窗口定位复用 `RequestPanelWindowBounds`，先显示再异步查询，退出／重入隔离迟到结果。绘制按屏幕高度分列，并为多字符键帽预留宽度。

Text Select 与 Quick Switch 的模式徽标复用共享呈现及主题强调色，仍接受 `mode_indicator` 覆盖。快速切换标签已输入前缀复用 UIHint 的默认黄色，可由 `quick_switch.ui.matched_text_color` 覆盖。文字选择通过 `HintView.highlighted_hint` 将当前单个预览接入共享高亮缓存；默认 `Primary+Q` 的普通模式绑定优先于搜索编辑确认，返回 Normal 且不复制，Esc 仍返回来源模式。

## 文字选择与可配置导航

macOS 的临时快扫区域可先显示并选中，但只提供位置；`api/text_select_preview/` 集中选择纯数据处理实现，其他平台正式构建使用零大小、可内联消除的空实现，跨平台测试可模拟 macOS 增量，Windows 正式路径不维护快扫状态。输入未完成的标签前缀时保留当前标签，将其他增量暂存，前缀不再匹配或输入清空后恢复更新。准确 OCR 按区域替换临时行时保留已冻结的标签、几何和选择。融合可能把同一行拆成多次交付，选中含临时行的区域后，复制和细分等待整轮识别成功并在各临时行有对应准确结果时执行；缺失、失败或取消时不复制不完整文字。更改输入、其他操作、重扫或退出会取消待执行动作，迟到结果仍遵循扫描代次及快照规则。只选中已识别的普通区域时仍可在扫描完成前复制或细分。

区域进入词语层时只保存待分词原文与父层快照，不建立临时字符选择或数字候选；等待画面的预览及计数直接来自原文。等待期间保留输入，复制、选择和翻页仍不可用；有效分词结果返回后一次建立正式词语选择与编号，再恢复查询、消费数字并生成最终预览。字符层继续同步拆分。基础选择快照仅属于区域层，细分层的选择及顺序由 Frame 独立维护。

`src/modes/text_select/` 是独立 OCR 文字选择状态机；`document.rs` 保存原文范围、区域位置及区域／词语／字符选择快照；词语／字符仅保存文本范围，原位几何只属于区域层。第一层共用 UIHint 的 `ScanSession` 增量去重、查询缓冲、匹配排序与空格多选过滤，直接输入搜索，普通 `c` 输入、`Alt+C` 细分。区域层复用 `ui_hint.overlap_cycle_key`（默认 Shift）及公共 Presenter 重叠层计划；首次按下按需规划，保持时置顶下一非默认层、松开回到默认层，左右侧和重复事件不重复推进。增量／过滤使旧计划失效，保持期间随可见结果重建；细分、重扫与退出清理保持状态。输入编辑使用共享 `Selection` 与 UIHint 编辑键。查询未匹配时继续接收扫描；条目确定选中后冻结快照，重置才应用迟到结果；上一层恢复选择。复制键配置在 `text_select.bindings`，默认 `"mod+c enter" = "text_copy"`；前者按系统解析为 Ctrl+C／Command+C。所有绑定到该动作的键始终复制面板勾选文字，与查询和输入选区无关。`text_clear_input`（默认 Ctrl+X）清空整个查询及光标选区，仅按正常查询变化刷新；不复制、不改变层级、不取消待定分词，细分层已确认的勾选保持不变。空查询清空为无操作。共享编辑器的 Copy／Cut 不接入该模式。区域层按原文顺序；词语／字符层在 Frame 中同时保存勾选状态和勾选顺序，预览、复制及下一次细分均按该顺序拼接。取消勾选移除该项，重新勾选追加到末尾；全选保留已有顺序，将缺少的项按面板顺序补到末尾，清空同时清除顺序。翻页、清空查询和返回上层保留对应快照中的顺序。仅待定复制的成功回执执行 `lifecycle.after_copy`，默认返回 Normal；通过共享生命周期命令支持 keep 保留实例与选择、restart 重新扫描、return 返回来源及指定模式。失败或无选择不执行生命周期。字符按 Unicode grapheme 拆分。词语／字符层初次细分时默认全选，固定按全部条目生成从 1 开始的十进制编号，独立于区域层 hint_characters；搜索和分页不重新编号。selection_input.rs 解析单个编号与闭区间：单号切换勾选，1-20、1-3 4-5 勾选区间全部项，重叠项不重复，倒序区间按输入方向组合。编号或区间终点复用 api::hint::match_label_input 的共同匹配逻辑；匹配和绘制共用 panel_hints 返回的当前页候选，不按总条目数推测冲突。当前面板中的完整标签无其他前缀候选时立即生效，隐藏的其他分页或筛选结果不阻塞。输入编辑、翻页及异步搜索结果更新后沿用同一识别流程；输入期间不先重置当前页。有歧义时由空格、复制／继续细分确认末尾项。单号自动切换后紧接连字符时，用仅记录该项原勾选位置的撤销信息恢复选择，将其作为区间起点；不复制完整 Frame。其他输入、编辑、操作或换层结束该续写状态，避免把 12 或 1-20 的前缀 1 提前执行；越界、溢出和不完整区间保留输入，不部分执行。消费编号时保留搜索文字和 Unicode 光标／选区。文字／简拼仅筛选当前细分层跨全部页的候选，不改变勾选与复制顺序；复用共享 SearchText，首次搜索按批次准备并由维护计时器继续，数字操作不建立索引。清空输入恢复全部候选并保留确认选择；翻页后根据新面板候选重新识别待定编号，返回上层恢复快照中的勾选。默认 Tab 触发单一 `text_cycle_page` 动作，末页回首页；区域层和待分词阶段不翻页。空输入时 Backspace 的 `text_clear_selection` 清空勾选，Ctrl+A 的 `text_select_all` 全选当前层（跨全部页）；两动作在有输入时让给同键的共享编辑器删除／全选输入操作，构造模式时按实际绑定编译这两套用途，不依赖 Primary 别名。Alt+Backspace 返回上层，Ctrl+Backspace 重置。显式区域全选／清空更新空查询基础选择并冻结已有快照，未收到结果时不会冻结扫描。分页提示取配置中实际的循环翻页键，不固定显示旧 PageUp／PageDown 操作。

只请求 Vision 文字，不请求 AX/UIA、轮廓或词／字符坐标。只有区域层在原位置画 Hint 和选中包围框；词语／字符层均在面板中显示带勾选标记的选项，按每项词长独立计算宽度、顺序排满一行并沿用分页；单个长词不会加宽整页。`ui.word_min_width`／`char_min_width` 分别控制两层的最小宽度，短屏幕仅压缩过宽卡片并省略长文本，保持完整选择与复制。原位标签高亮和包围框在细分层都关闭。`src/presentation/text_select.rs` 复用 Hint 输入、面板样式和原生窗口，信息区仅预览待复制文字及数量，层级使用标准英文 mode indicator。初始／重置的空区域查询只呈现 Hint 与输入框，输入后显示预览；词／字符层即使清空查询也保留继承选择的预览。紧凑文字行高与数量行按字号布局，垂直内边距取共享信息面板的一半；数量和卡片之间增加留白与分隔线，卡片标签与正文使用相邻行框。信息面板宽度使用 `ui.panel_width`，仍走共享定位与屏幕边界限制。同一文字区域内的 OCR 行按软换行拼接，整段字符流直接复用 UIHint 搜索 OCR 复制的 `write_ocr_text` 清理；跨行汉字空格和中文标点间隙同样移除，英文词间保留一个空格。区域之间保留段落分隔，预览以一个有界段落交给原生字体排版，按实际面板宽度自然换行，不再按估算字符宽度插入硬换行；预览、细分和复制共用清理后的文本，不保留扫描行宽。包围框的编译后颜色、线宽和二维外扩边距从 `TextSelectView` 传入；只有第一层选择移动鼠标，使用原区域右下角加 `text_select.ui.pointer_offset`，默认 `[12, 12]`，与包围框 padding 独立。首份场景先提交，后续扫描增量和索引预热使用可取消的零延迟维护计时器。系统分词先提交等待画面，再通过 `Command::SegmentText` 发起，确保同步回退的结果不会被旧等待画面覆盖；取消／返回／重置撤销所有权，迟到结果按 id 丢弃。

Grid、Recursive Grid、UIHint、屏幕选择器的导航通过 `first_level`／`previous_level`／`confirm_selection` 等绑定接收；`cancel_selection` 返回本模式的来源，不能等同于全局 `escape` 进入 Idle。普通 UIHint 的 `reopen_selection` 只在选择完成后返回，保留原 Tab 语义。Normal 盲操的多层导航从所选网格模式取得 `first_level`／`previous_level`，不覆盖显式 Normal 绑定及应用覆盖；生成的绑定不向继承 Normal 的模式传播。Window Editor 的区域前缀及 Restore 的翻页也使用 WindowAction。数字／标签输入、空格分隔及大小写范围选择属于输入语法，操作键由绑定表决定。
