# 绘制与性能

目标优先级：**响应速度 → 内存占用 → 局部实现便利性**。以实际场景和测量决定方案，不固定某个容器、缓存策略或线程数量。

## 入口

- 场景协议与借用视图：`src/api/overlay.rs`、`src/api/presentation/mod.rs`。
- 场景生成：`src/presentation/`；提交协调：`src/app/runtime/overlay_coordinator.rs`。
- 普通／递归网格共用 `src/presentation/grid.rs` 的内部网格线几何，分别保留样式、预览、裁剪和隐藏策略。
- 原生绘制与帧时钟：见 [后端](06-platform-backends.md)。
- 日志：`src/support/logging.rs`；性能工具：`tools/perf/`、`tools/`。

## 优化原则

- 文字选择细分从已经生成的复制预览直接建立不可变文字快照，不重新遍历并拼接选区；词语／字符面板借用当前页 hints、原文范围和选择标记，不逐次收集临时卡片数组。布局缓冲仍保存测得的宽度，避免绘制时重复测量。

- 焦点应用为空或所有模式均未配置应用绑定覆盖时，直接使用空绑定配置键，不创建模式列表和空覆盖快照；存在覆盖时仍比较完整解析结果，窗口标题变化和失去焦点都能触发必要的建表。变化后的同一份覆盖结果直接用于建表和保存快照，不再次匹配应用；键表借用基础绑定与覆盖，仅实际存在覆盖的模式建立借用键值的有序合并视图，保留后项覆盖及原始键排序决定的组合键冲突顺序。键表按注册索引直接替换对应槽位，不暂存整批新表或反复收集模式 ID；路由缺失时同时清除旧表与临时触发键。重建过程中不派发事件，前缀与插件绑定仍在所有基础表完成后编译。
- 显式快捷键解析直接借用别名表和解析结果，不复制整表或借助线程局部作用域；只有配置反序列化需要隐式作用域，嵌套和异常退出仍恢复原状态。计划替换转移路由所有权，避免复制整份即将丢弃的路由。
- 临时层、普通继承和拖动辅助使用路由安装时展开并去重的模式 ID 清单；直接继承清单被替换，不保留第二份树或复制绑定。反向临时继承仅在原始按键接管会剪掉分支时多保存一条顺序。逐键查询不递归、不维护 visited，也不按已按键总数分两轮遍历；候选绑定和模式 ID 均借用，仅选中动作才复制共享引用。passthrough 直接匹配原按键集合，无需构造剥离集合；标签按键归属只在层内阻断继承时判断。触发组合在配置编译时生成 `KeyChord`，首次建表时直接转移到模式槽位，之后复用；建表不重新解析或复制临时键，注册和替换路由不另维护转移流程。禁用状态在路由编译时确定为 `None`；字符绑定路径在禁用时直接借用已编译字符键，跳过临时层已按键筛选和中间按键列表；启用时仅查询一次触发槽位。
- 按键的保持状态按已解析的绑定动作分类，不按物理组合键数量推断；动作序列和显式窗口目标保留完整的递归分类语义。普通移动及网格动作直接借用已解析的 owner，只有窗口动作进入窗口会话归属分支；组合键、临时层和应用覆盖仍沿原路由解析，释放沿按下时保存的绑定与 owner。
- 热路径复用窗口、buffer、图像、字体和已编译样式；没有测量依据不引入逐帧全屏分配。物化保留图层时跳过空前景，不因空追加而复制整个共享图元存储。
- 完整场景在统一提交入口先借用检查层序；已排序的共享场景保留原所有权，不为无操作排序触发写时复制。窗口注释和标签共用一次稳定排序得到的位置映射，标签按映射原位交换，不再执行第二次排序；相同层级的原始顺序保持不变。
- 焦点快照更新复用已有应用标识与标题的字符串缓冲；首次取得焦点仍创建快照，失去焦点释放快照。事件继续拥有原输入并完整派发，应用排除与覆盖绑定读取更新后的快照。
- 普通／递归网格的等尺寸单元格在每份场景内按层共用已拟合的标签样式；单键直接构造内联文字。Grid 的标签及网格线按批次借用可变存储，不逐图元重复检查共享所有权；保留原有图元顺序、内容和容量。递归网格的自定义文字按完整字符数拟合，预览仍只重复其首字符；拟合与隐藏判断每层计算一次，不保留跨场景缓存。
- Grid、Recursive Grid、Bisect 通过具体几何类型与关联样式做静态分派，输入、细分限制、重置、切屏重放和视图构造都不在运行时区分三种模式。共享选区历史及生命周期源码由编译器分别实例化；仅保留按键、选择状态、深度和边界等功能判断。字母选择共用一次布局查询；Bisect 无字母布局查询、预览文字或字体配置。Normal 静默定位的几何也在装配时选定，不给普通移动帧增加分支。
- 空前缀直接接受全部 Hint 标签，不逐个解码文字；通过前缀匹配后共用一次计算的字符数，不重新统计每个标签。矩形计算在规划循环中内联，使等宽标签共用已计算的宽度和放置参数。
- Hint 场景批量借用标签及边框的可变存储，一批只检查一次共享所有权，不逐图元触发写时复制检查；保留原有标签顺序及窗口注释边界。 已证明为单个完全重叠组时，缓存标记允许一次遍历按原顺序绘制，仅将当前选中标签放到最后；混合重叠组仍按原有稳定层序绘制，过滤、重扫及缓存释放必须清除旧标记。
- 进入空查询搜索时保留完整标签，不再经过空过滤清空并复制一遍；索引继续按首屏后的预热调度准备，空查询不强制同步完成。从完整标签进入时复用重叠层规划；存在标签前缀或恢复非空查询时重新规划，不能复用过滤前的可见层。
- 内容与位置更新分开；同矩形且身份无歧义的扫描元数据在原槽位更新，单项更新复用几何索引，跳过全量映射和遍历；批量或身份有歧义时仍执行完整协调。未改变普通标签场景时跳过重叠规划和重绘，仍调度搜索预热；静态内容未变时避免重复布局和绘制，但失效条件必须覆盖主题、DPI、屏幕及会话变化。
- macOS 普通静态场景沿用原索引的形状图层，标签变化时只重新配置内容变化的形状，避免重复创建线条路径；标签槽位重排后，完整内容未变则只恢复可见性，跳过文字分析和原生属性重设，未配置的离屏槽位仍保持隐藏；屏幕位置、窗口创建或 backing scale 变化仍强制刷新。保留背景与普通场景切换时比较实际基础场景，不新增形状缓存。Windows 沿用已有表面及损伤区域重绘，不能在已清空的区域中跳过未变形状。
- 两端共用 `platform/common/overlay_geometry.rs` 的文字像素对齐与双行徽标布局：尺寸独立于位置向外取整，两行共用像素对齐的右边界，完整帧与位置快路径保持相同布局。macOS 在面板局部坐标按 backing scale 对齐文字及其父层，文字 bounds 或倍率变化时重绘原生位图；Windows 场景已完成 DPI 换算，按物理像素对齐 DirectComposition 的表面局部文字和最终偏移，GDI 回退使用相同徽标布局，不再次乘 DPI。保持字体、窗口和位图复用，单纯移动不重新绘制或改变表面尺寸；1x 屏幕不强制使用 2x 位图后再缩小。
- 完整场景去重必须同时核对当前位置。位置快路径不复制共享场景；runtime 及两端原生渲染器分别保留动态位置，后续完整场景返回旧坐标时仍更新原生图层，不能把旧完整帧误当作当前显示状态。Windows 原生偏移写入失败时使对应位置失效，下一份完整帧重新设置。
- Windows DirectComposition 的指示器明确以游标为参考放在其上方，静态背景位于游标下方；`AddVisual` 的参考图层为空时，`insertAbove=true` 表示放到所有同级图层下方，不能用它表达置顶。
- Windows GPU 窗口只在首份完整帧提交成功后显示；后续完整帧复用可见窗口。关闭、截图隐藏及尺寸重建会销毁旧窗口，新窗口重新走首次显示；提交失败不登记为成功的完整帧，不增加独立的显示状态。
- 连续移动按真实 elapsed 积分，使用原生显示时钟；不靠忙等或提高空闲轮询频率改善手感。 仅移动指针的帧直接返回单条命令，滚动按键状态与滚动帧的多命令构造各自留在独立函数，避免新增滚动拖慢常见移动路径。信息面板批量借用标签和形状缓冲，一次预留面板与随后输入框所需容量，避免逐条检查共享所有权和多次扩容。
- 合成移动成功后，只有活跃模式订阅指针事件或存在挂起的 Window 时才查询跨屏通知所需边界；仍更新真实指针位置、拖动释放和覆盖层位置。挂起的 Window 先接收通知，随后重新检查活跃模式的订阅，保留模式切换时的事件顺序。

- 两端在同步按键之后、后台扫描／维护之前直接读取就绪显示帧，不等待后台批次数阈值。`BackgroundBudget` 仅在 macOS 为回退原生 run loop 提供处理机会；Windows 不维护无消费者的后台计数，不查询刷新率、不新增移动计时器。
- 活跃会话复用容量；结束／重扫释放目标内容、搜索索引与场景，仅保留最多 16,384 项的空标签缓冲供下一次扫描复用，超过上限直接释放，不逐按键收缩。
- 扫描生产、融合计算与上屏分离，后台融合按来源轮转、按 CPU 成本调节有界份额；不把内联容器容量当作发布门槛。已有少量结果立即可交付，输出邮箱吸收重复唤醒与快于绘制的增量。职责与生命周期见 [UI 扫描](05-ui-scanning.md)。
- 后台工作有取消及积压策略。可替换状态可合并，可靠完成事件不能随意丢弃；当前可靠通知队列没有硬容量上限。
- 到期 timer 仍按 id 排序并只派发本轮快照，回调取消的后续项跳过，已派发的 timer 再次安排零延时工作时留给下一轮。少量到期项使用局部内联存储，超过容量照常扩展；每项借用一次状态取得 owner、elapsed 并重排期限，不新增持久缓存。
- 禁用日志不格式化参数；错误在恢复边界统一记录，稳定错误与请求上下文分开。生产线程保留原始时间和线程身份、去重后入队，由单个 writer 顺序执行文件／控制台 I/O 与轮转。队列最多 256 条；正常首条 Error 不等磁盘，但饱和时施加背压以免丢错误。flush、panic 和退出 shutdown 等待已排队记录，shutdown 先排出重复计数再关闭队列并 join；writer 自身故障不允许等待自身。flush 不承诺断电持久性。

性能验证区分 CPU 微基准、原生确认、输入到像素、堆分配、RSS 和 GPU 资源。用独立构建目录做基线对照，关注 p95/p99、冷启动和重复进出后的内存；不把局部收益外推为整机收益。入口见 [验证](08-build-docs-and-tests.md)。

搜索快捷键与样式在配置编译阶段处理，编辑会话只共享已编译快捷键切片。查询归一化、匹配排序与候选更新放在独立的非内联搜索函数，普通标签生成不进入这些临时量的栈帧。搜索索引的规范化文本与简拼共用一个字符串，以保存的边界分别匹配，不能跨段命中；为 ASCII 和无大小写转换的名称一次预留全部容量。ASCII 名称和英文角色只保留在字面文本中，简拼段仅保存额外的中文角色简拼，避免重复存储和转换。需要 Unicode 大小写转换时保留整串转换，避免破坏上下文相关映射。混合文字的简拼转换按段复制 ASCII，仅为非 ASCII 字符查询拼音，保留空格、标点和不可转换字符。多个 ASCII 元数据字段直接写入最终索引，避免临时拼接字符串；含 Unicode 的字段继续使用整串转换。逐字符修改复用查询容量；查询不变不重筛，光标／选区不变不提交场景。退出搜索保留本轮查询与索引容量，退出 UIHint／重扫释放；字符捕获在退出及错误恢复时关闭。绘制场景仍有所有权分配，查询索引分配测试不能当作整次输入零分配的结论。

点位检查及其移动状态只在结果信息面板出现时按需创建，复用成员容量，面板隐藏后释放。普通标签事件跳过检查处理；信息面板和搜索框布局使用独立函数，普通标签绘制不进入面板的大型栈帧；信息面板中的单点及已确定多点均开启取色及刷新 timer；颜色 concat 复用成员样本缓存并串行异步采集，switch 仅采集当前检查点。普通标签、空搜索及没有可预览结果的搜索不调用原生采样。一次 Hint 事件完成过滤、检查状态和命中更新后只生成一份最终场景，关闭输入／确认移动先于恢复场景，场景先于采样、复制回调及生命周期切换。不要为了合并绘制改变这些命令顺序。

首次标签场景提交后主动预热搜索文本／拼音索引，不等用户搜索；仅处理当前 UIHint 会话已有的扫描结果，未进入模式时不为搜索预热扫描桌面或创建索引。复用零延时一次性 timer，通常每次最多处理 256 个目标；已有文字查询等待时，后续 timer 每次处理最多 1024 项，减少调度开销；未完成时立即重排同一 timer，不增加等待或周期计时器。Engine 每轮只派发该轮到期 timer 的快照，因此下一份工作前会重新处理输入／原生事件；不是新线程，也不等待原生出像素确认。追加目标保留已建索引前缀，先提交标签再预热新增部分；实际删除目标才清空索引，未命中的撤销通知和重复目标保留已有索引。空搜索和纯标签查询不强制完成索引；最多 2048 个目标的小列表直接完成文字索引，避免调度与准备界面的额外开销；更大列表的普通文字输入最多补齐 256 项，未完成时显示准备状态并清除旧候选，后续预热完成后匹配最新查询。取消、重扫和切换为纯标签查询清除等待状态；用户提前确认时同步完成最新查询，不能把旧候选或部分匹配作为最终选择。重扫／退出取消预热，迟到 timer 不恢复已结束会话。预热仍消耗 CPU 和保留内存，不能声称未搜索时零开销；固定控件类型的中文别名和简拼使用静态对照，只转换名称／OCR／辅助信息。

窗口移动／缩放按键只提交原生请求；几何确认前不重复生成旧边框和卡片，状态提示及显式目标选择仍立即重绘。确认结果驱动两端共用的场景生成，不能用预测位置冒充原生成功。macOS 覆盖层复用 Backend 的显示快照，显示变更或首次快照缺失时才枚举；枚举失败重新标记刷新，避免永久使用过期数据。

窗口卡片及面板注释的避让候选先与当前最佳距离比较；不能胜出的候选不再遍历已有矩形检查碰撞。候选生成顺序、严格更近的替换规则及拥挤时的重排回退保持一致，不增加跨帧缓存或改变最终位置。

选中窗口卡片在现有应用名／Tab 组标题行加入勾选标记，复用原有卡片尺寸与标签槽位。可配置的选中底色与轮廓在 `WindowStyles` 中预编译；文字缓存包含逻辑组选中状态，几何变化仍复用文本，选择变化才失效，不新增逐帧字体或原生绘制对象。

动态快捷键帮助直接遍历已编译键表，配置项与模式补充项写入同一数组，最终只排序、去重一次；预编译窗口帮助计划由 Registry 对应模式槽位单独拥有，不另建 ModeId 到计划的有序表，场景重算时只借用当前计划；Overlay 不再缓存一份当前计划或维护其切换／重建失效。条目数组直接属于计划，不单独再套一层 Arc；返回模式名称在同步绘制时借用，仅计划建表时保存一份所有权。快捷键帮助直接绘制分组后的键位／动作条目，不保存仅含一行的嵌套字符串数组或逐条宽高副本；列高度预先累计，行坐标逐行推进。多个按键合并在同一行、方向族缩写、两列布局及窄屏回退保持原语义。预编译时只复制两种列布局需要的条目，不复制整个分组及页脚；同步绘制借用条目和预编译布局，不为临时传参转换成 Arc。缓存检查得到的详情、标尺和预览由同一次绘制借用，随后交给原有会话缓存，不重复向 Mode 查询；公开 Mode 接口保持不变。

窗口帮助的宽度由键位、模式标题和数字输入决定，窗口标题、设备名与操作结果只在现有状态行内省略显示，不驱动列数或整面板字体缩放。窗口、Quick、Editor、Tab 与恢复列表保留空的反馈行，结果出现或清除不伸缩面板；原有多选输入布局保持。Windows 仍复用现有完整帧绘制与场景去重，不增加脏矩形、图元缓存或新的表面。

窗口多选帮助的固定键位说明在进入输入时生成，随输入状态释放；逐键刷新只构造当前数量和光标文字。编辑动作仅在文字改变时重新解析编号和恢复勾选集合；光标／选区移动继续更新原生窗口预览、指针和输入显示。目标读取按逻辑窗口借用遍历，计数和布局生成不先收集完整身份列表；需要修改会话或逆序提交的请求仍先拥有目标身份。布局提交先检查编辑状态，只在 Quick 有待提交几何时读取操作目标，不在空闲、等待确认或 Tree 路径整理无用列表。

扫描会话的去重索引保存量化几何的紧凑哈希，碰撞链仍核对完整量化几何、名称和角色，不能把哈希相等当作目标相同。退休继续匹配原始矩形；首次批次和追加用同一 Entry 完成查找与写入，扫描完成／退出释放索引。


重叠层规划按连通组处理。若组内每个标签都与其余标签冲突，层数和前后顺序已由绘制顺序确定，直接赋层，跳过候选择色、压缩和评分。标签长度先由保留的 LabelPlan 与实际字符集推导，等长时复用估算宽度；流式追加、退休替换和搜索过滤不按当前可见数量重新推断。按行带保守证明互不相交的布局直接写入无叠层计划，不进入图工作区；等长批次中连续相同矩形的组若互相分离、组内实际遮挡成立，则直接写入各组层序。混合长度但共用左边、右边或中心对齐的密集标签，仍逐对确认全部遮挡关系后才直接赋层。这些路径不受 128／512 个标签门槛限制，不创建临时打包数组；其余图形仍使用原有候选算法。判定使用实际冲突关系，不假设相同位置或矩形相交就必然互相遮挡。图及着色工作区留在独立函数，避免首屏的已证明布局进入大型栈帧。

每个着色候选仍最多压缩两遍；完整一遍未改变任何颜色时已经达到该顺序的不动点，跳过重复遍历。候选顺序、评分、规范化及最终层序保持一致，不能以减少候选或重叠关系换取速度。

宽标签计划先检测是否存在冲突，再按需构图。依据布局跨度相对标签尺寸的比例选择横向或纵向扫描，减少长列表中同时保留的候选；退化或溢出的估计保持横向扫描。检测复用扫线候选数组，按垂直于扫描轴的包围范围保守排除候选；扫描线越过最早到期的区间后才清理候选。范围判定必须保守，保留不等高标签、浮点边界及无效几何的原有语义，不改变实际遮挡判定和最终层序。

512 是小结果集的内联容量，不是扫描条数上限；更大的计划按实际结果复用动态容量，不按窗口数猜测目标数。宽图先保存实际冲突边；稀疏时生成连续邻接表与行偏移，实际边存储将超过位图时改用稠密位图，释放替代的边缓冲，避免高重叠布局的内存与计算回退。稀疏布局无需预先分配目标数平方的位图，两种表示都按同一顺序访问邻居。稠密非捷径布局的计算仍随实际冲突关系增长。层序按实际深度使用 2／4／8 字节，深重叠以 u64 打包两个 u32 字段，避免 16 位字段溢出，不统一放大为 u128。

搜索文字通过 OverlayLabel 的紧凑编辑位置描述光标／选区，原生后端使用实际字体宽度定位，公共层统一控制装饰高度与裁剪。DirectWrite 保留单个编辑布局，命中布局时不重新填充 UTF-16 缓冲；布局缓存为空时跳过用于清理缓存的标签遍历，已有缓存仍检查编辑／只读滚动标签，离开时照常释放；macOS 复用文本测量及光标层；隐藏／离开编辑场景释放相应缓存。macOS 固定面板文字按字体行高垂直居中，不复用普通标签的光学基线偏移。

标签身份匹配和原生槽位的纯 Rust 重排集中在 `platform/common/overlay_reconcile.rs`，公共测试在两端运行。macOS 保留原生图层池及同层级的兄弟顺序，普通及保留背景标签完全离开当前显示区域时隐藏图层，跳过文字排版及属性更新；可见性判断包含边框和抗锯齿留量，重新可见时按未配置路径刷新文字。恢复保留背景的省略标签时，不得显露尚未配置的离屏槽位。图层池扩容后直接按匹配索引换位，未匹配槽位重新配置；首屏、原位更新及尾部追加不创建换位索引；全部旧槽位已按顺序匹配时，新增尾部保持未匹配，不回退重建身份哈希表。保留原顺序且只向前压缩的过滤直接交换槽位，不构造位置映射；乱序或向后移动仍使用原有临时正反索引，不另存期望槽位和占用标记。编辑图层身份不含查询文字，过滤与输入更新时保持槽位稳定。macOS 文字变化在禁用动画事务中清除旧 contents 并标记重绘，由系统统一提交；输入线程不得逐图层调用 displayIfNeeded 强制同步绘图。CoreText 每段文字只排版一次，再读取 UTF-16 插入位置，避免逐前缀复制与重复测量；只读滚动文字需要重新布局时只测量总宽及计数边界，不构建逐字符位置。编辑态已有的位置仍随同一份文字保留，切回编辑时仅在位置缺失时重新测量，避免为了释放小缓冲拖慢状态切换。普通标签仍预留前缀高亮位置，仅移动光标不重建文字。Windows DirectComposition 复用绘图表面和变化区域，GDI 回退重画完整帧，均不维护逐标签原生图层池，不调用槽位重排。

共享搜索在会话内复用词项范围缓冲，每个词项在候选循环外解析标签标记，去重后按首次出现顺序扫描；只有多个不同词项才维护候选去重标记，单词查询跳过标记清零及读写；重复粘贴词不会反复遍历目标，单独的 @ 不扫描目标。显式 `@标签`／`标签@` 直接比较标签前缀与长度，不读取或同步补齐文字／拼音索引；与普通词混合时仍完成必要的文字索引，避免漏掉未预热目标。退出 UIHint／重扫释放范围缓冲，退出搜索保持容量供下次复用。

卡片标题和单行信息预览按既有估算字宽截断时，字节长度足以证明可容纳便跳过测宽，否则只扫描到首次超宽；省略号、Unicode 字符边界及控制字符清理规则不变，不为丢弃的长后缀测宽或建立缓存。

搜索输入不在展示层按估算字宽提前截断，后端复用现有字形位置滚动和裁剪，短输入保持左对齐；输入与 Point 复用同一文字布局和固定基线，Point 隐藏光标并显示末尾。圆点与左侧文字使用对称内边距，多点计数并入同一次原生布局，按实际宽度右对齐并紧邻圆点，查询与计数只保留固定小间距，短查询不重复绘制内联后缀；原生布局变化时缓存计数宽度与文字区边界，后续帧不重复查询计数字形位置。信息栏使用完整列宽；不维护字体分类或增加独立测量缓存。

搜索匹配度和类别优先级在配置装配时编译为固定查表；过滤时按九个固定分组连接结果索引，每项仅保存一个后继索引，连续同组成员使用默认相邻后继，不进行比较排序。首项自动显示，point_next 以 O(1) 推进候选游标，不重新扫描文字、排序或生成候选字符串。文字匹配复用已归一化索引，首词直接判定完整匹配；单个 ASCII 字符使用字符查找，多字节词先用布尔包含检查排除未命中，再查看实际匹配位置的相邻字符判定完整词、词首和包含匹配，两条路径共用 Unicode 边界规则。纯 ASCII 数字／标点查询在原文未命中时不重复搜索简拼，因为转换只会引入字母；含字母或 Unicode 的查询保留原有匹配。查询包含可转换汉字时在词项准备阶段排除不可能命中的简拼表示；字面文字已匹配时不重复搜索保留的拉丁字符简拼。循环顺序与显示标签顺序、完整标签编号空间、已解析多选集合分开，避免调整优先级改变重叠层与选中身份。查询和结果变动使顺序失效，退出搜索复用容量，重扫／退出会话释放缓存。

Hint 场景在绘制标签前计入搜索信息栏、色块和点位图元容量，避免追加小面板时扩容并复制整份标签／边框缓冲。

首份 Hint 场景保持普通标签绘制路径，提交后只共享已有场景；复用搜索预热轮次准备共享高亮样式。完整目标顺序的场景直接按目标位置读取并核对标签身份；无前缀且无重叠重排的有序过滤场景复用可见 hints 的目标编号顺序进行二分定位，核对实际场景标签身份，不新建槽位表。唯一标签同样不建立重复索引。搜索中的重叠场景复用已有层序，在实际输出每个标签时记录目标对应的槽位整数；复用会话内数组容量，未显示目标填哨兵并在使用时核对标签身份，不再单独遍历文字建立哈希索引。普通首屏不分配该数组；首次普通重叠场景在提交后借用已有 hints 和层序，每份最多处理 256 个目标：每层通过已排序场景查找一次起点，同层按源顺序推进，完整重叠组直接使用层号定位，不遍历文字建哈希表或重算重叠排序。只在预热阶段分配整数槽位数组；尚未填入的成员可即时查找，Tab 不等待预热，不新增 timer。稳定目标层通过 `OverlayScene.retained` 共享；搜索 Tab 只生成当前高亮标签、信息栏、输入栏与点位图元，直接读取重叠槽位或利用有序结果定位当前槽位，将其普通标签省略，避免透明高亮叠在旧文字上。提前进入搜索时可按标签码查找尚未准备的成员，不阻塞等待预热。查询或扫描改变标签集合时重新建立稳定层和必要的索引；重叠层、主题、DPI、范围和前缀改变也使场景失效。结束／重扫释放会话缓存，过滤后不存在的成员不补画。无缓存的 Presenter 仍支持完整场景路径；保留原有稳定层序和当前项置顶语义。

Windows DirectComposition 在稳定层身份及表面几何不变时，只清除并重画前后高亮与面板的变化区域；首份普通场景的形状和标签存储与新保留背景相同时，也沿用已有画面，旧普通图元不是待擦除的前景。先确认存在损伤区域，再按需建立稳定图元的空间索引；无损伤和完整绘制均不预建；区域查询保留绘制顺序并重画所有相交图元，不能仅擦除旧标签而破坏重叠内容。复用原有 GPU 表面，不分配逐帧全屏副本；DPI 缓存把首份普通标签的已缩放存储交给保留背景，避免再复制／缩放全量标签。比例变化在任何查询前同时清除背景和前景缓存，空前景不保留旧标签。其他普通场景、稳定层更换、嵌套保留层、表面／范围变化走完整绘制，GDI 回退通过 `materialized()` 保持完整绘制兼容。两端通过 `OverlayScene::retains_static_content_from` 核对背景来源、裁剪与底色。macOS 首次进入保留背景且来源存储不变时，直接复用已有图层槽位，不重建槽位映射或遍历设置全部背景属性；首次前景仍完整配置，不能把旧普通标签当作旧前景。后续保持稳定层槽位，只恢复前一普通标签、隐藏当前普通标签并更新变化的前景图层；主题、DPI、显示几何变化重新配置，退出释放前景池。原生像素对照与交叉编译不能互相替代。

搜索候选只保存完整 search_hints 中的位置，显示标签在过滤时原位更新，身份和几何未变时跳过复制；不再维护第二份候选标签或逐查询清空后全量复制。标签层与重叠规划只因实际可见标签的身份、顺序、几何或待应用扫描结果变化而重建；匹配排序、预览目标、信息栏数量及查询是否带尾随空格不单独使标签层失效。恢复全量显示同样原位核对，仍需补回此前被过滤的标签。过滤结果需要新槽位索引时，也先提交场景和当前预览，再由已有预热轮次分段准备，不能在查询路径同步建完整索引；整数槽位按目标空间一次预留容量，避免逐批扩容搬移。会话内过滤失效只清除场景和索引内容，复用索引容量及同一主题的高亮样式；主题变更重新解析样式，退出／重扫完整释放场景缓存。Tab 借用缓存，不为检查预热状态重复增减场景引用；准备完成前保留身份查找兜底。手动预览独立保留 label／几何身份，原始索引因流式追加或退休变化后重新定位，不能依赖旧向量位置。

Text Select 共用 UIHint 搜索过滤器、保留标签场景缓存和输入编辑；仅索引文字内容、不加入合成角色信息。可见标签身份／几何不变时复用同一静态场景，光标移动只更新动态面板。查询过滤传入零同步索引预算，先提交输入和 Hint，再按每回合 256 项（查询等待时 1024 项）预热同一搜索索引。明确复制／细分可同步完成剩余索引；显式 @ 标签无需索引。后续扫描增量复用 ScanSession 暂存／去重并合并到维护回合，不逐批重建拼音。已有结果时，空增量仅更新扫描状态并保留搜索预热，不触发段落及索引重建；此前排队的增量和仅撤销目标的批次仍须应用。面板仅绘制有界文字预览和最终字符页，不绘制重复的区域／词语列表。

OCR 段落分组先按行的 y／x 稳定排序；以本次输入的最大行高证明旧分组前缀不可能接续时，才推进匹配起点。不能用当前行高提前排除后续大字号行可能接续的段落；前缀被可接续段落阻挡时继续原遍历。最小间距、相同间距时的创建顺序、合并后按区域 y／x 的稳定排序和文字清理规则保持不变。每组内联存放两条行引用，更多行才分配；匹配游标仅属于本次分组，不保留跨批次索引或缓存。流式更新仍经维护计时器合并，选中后的冻结与重置沿用原有快照语义。

文字选择细分层的文字搜索、索引维护和翻页不改变勾选时，跳过完整选中文字与摘要重建；数字确认和区间续写撤销仍即时更新预览。拼接与摘要复用当前会话缓冲，退出时释放输出、摘要和基础选择容量，不按每次输入收缩。输入长度与 Unicode 截断统一由共享 Selection 处理，仅实际插入的空白触发数字提交。

细分层标签在重新索引前保持固定，可见候选始终是其有序子集；数字或空查询恢复全量且长度已经相等时跳过复制。重建索引只准备候选，调用方恢复最终查询后再过滤，不先执行一次临时空查询过滤及摘要重建。词语分词等待期不生成将被结果替换的字符范围、勾选数组或候选索引，生命周期见[模式生命周期](04-modes-and-lifecycle.md)。文字过滤继续批量生成结果，索引预算、候选顺序和勾选状态不变，不另存查询缓存或脏标记。

搜索索引构造先按字节判断纯 ASCII 名称，只有包含非 ASCII 字符时才逐字符检查 Unicode 大小写转换；整串转换和上下文相关映射保持不变。文字细分的分词空隙直接追加到最终范围数组，不为每个空隙创建临时数组；追加时不能把空隙开头的 ASCII 串合并到前一个系统词语。系统分词结果为空时，直接进行 grapheme 回退，省去仅用于验证系统范围的边界表；非空结果仍校验完整 grapheme 边界、范围顺序和越界。

文字选择选中区域的边框直接借用 Frame 的区域与勾选切片，绘制时筛选，不在每帧收集临时矩形数组；边框关闭或处于细分层时传空区域切片。文字选择顶部预览使用 `LabelStyle.wrap` 的原生段落布局，Presenter 仅预留最多四行的矩形，不按估算字宽切割原文。预留高度只迭代借用文本切片；短文本由字节数直接证明无需截断，长 ASCII 前缀确认后续字节与 CRLF 边界后直接取片，其余仍按 grapheme 截断。单行卡片预览和勾选编号直接写入 OverlayText，不先创建临时字符串列表。卡片在单份场景内按勾选状态惰性共享编号／正文样式，不保留跨帧样式缓存；布局直接生成位置数组，短屏重排复用同一数组。Windows DirectWrite 使用独立缓存的自动换行／顶对齐格式及省略号，GDI 回退使用同字体的 word-break；macOS 复用 CATextLayer 自动换行并按单行高度设置基线。单行 Hint／输入框的格式保持独立；样式缓存和原生文本失效比较必须覆盖 wrap。预览最多提交 4096 个 grapheme，复制保留完整文本；字体、图层和绘制缓冲继续复用，不新增全屏像素副本。
