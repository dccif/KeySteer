# 绘制与性能

目标优先级：**响应速度 → 内存占用 → 局部实现便利性**。以实际场景和测量决定方案，不固定某个容器、缓存策略或线程数量。

## 入口

- 场景协议与借用视图：`src/api/overlay.rs`、`src/api/presentation.rs`。
- 场景生成：`src/presentation/`；提交协调：`src/app/runtime/overlay_coordinator.rs`。
- 原生绘制与帧时钟：见 [后端](06-platform-backends.md)。
- 日志：`src/support/logging.rs`；性能工具：`tools/perf/`、`tools/`。

## 优化原则

- 热路径复用窗口、buffer、图像、字体和已编译样式；没有测量依据不引入逐帧全屏分配。
- 空前缀直接接受全部 Hint 标签，不逐个解码文字；通过前缀匹配后共用一次计算的字符数，不重新统计每个标签。矩形计算在规划循环中内联，使等宽标签共用已计算的宽度和放置参数。
- Hint 场景批量借用标签及边框的可变存储，一批只检查一次共享所有权，不逐图元触发写时复制检查；保留原有标签顺序及窗口注释边界。 已证明为单个完全重叠组时，缓存标记允许一次遍历按原顺序绘制，仅将当前选中标签放到最后；混合重叠组仍按原有稳定层序绘制，过滤、重扫及缓存释放必须清除旧标记。
- 进入空查询搜索时保留完整标签，不再经过空过滤清空并复制一遍；索引继续按首屏后的预热调度准备，空查询不强制同步完成。从完整标签进入时复用重叠层规划；存在标签前缀或恢复非空查询时重新规划，不能复用过滤前的可见层。
- 内容与位置更新分开；静态内容未变时避免重复布局和绘制，但失效条件必须覆盖主题、DPI、屏幕及会话变化。
- 连续移动按真实 elapsed 积分，使用原生显示时钟；不靠忙等或提高空闲轮询频率改善手感。 仅移动指针的帧直接返回单条命令，滚动按键状态与滚动帧的多命令构造各自留在独立函数，避免新增滚动拖慢常见移动路径。信息面板批量借用标签和形状缓冲，一次预留面板与随后输入框所需容量，避免逐条检查共享所有权和多次扩容。
- 合成移动成功后，只有活跃模式订阅指针事件或存在挂起的 Window 时才查询跨屏通知所需边界；仍更新真实指针位置、拖动释放和覆盖层位置。挂起的 Window 先接收通知，随后重新检查活跃模式的订阅，保留模式切换时的事件顺序。

- 两端通过公共 `BackgroundBudget::take_ready_frame` 在同步按键之后、后台扫描／维护之前读取就绪显示帧，不等待后台批次数阈值。macOS 的后台预算仅用于给原生 run loop 提供处理机会；不查询刷新率、不新增移动计时器。
- 活跃会话复用容量；结束、重扫或峰值过去后回收不再需要的大对象，不逐按键收缩。
- 扫描生产、融合计算与上屏分离，后台融合按来源轮转、按 CPU 成本调节有界份额；不把内联容器容量当作发布门槛。已有少量结果立即可交付，输出邮箱吸收重复唤醒与快于绘制的增量。职责与生命周期见 [UI 扫描](05-ui-scanning.md)。
- 后台工作有取消及积压策略。可替换状态可合并，可靠完成事件不能随意丢弃；当前可靠通知队列没有硬容量上限。
- 禁用日志不格式化参数；错误在恢复边界统一记录，稳定错误与请求上下文分开。当前首条 Error 同步写入，慢 sink 仍可能拖延异常路径。

性能验证区分 CPU 微基准、原生确认、输入到像素、堆分配、RSS 和 GPU 资源。用独立构建目录做基线对照，关注 p95/p99、冷启动和重复进出后的内存；不把局部收益外推为整机收益。入口见 [验证](08-build-docs-and-tests.md)。

搜索快捷键与样式在配置编译阶段处理，编辑会话只共享已编译快捷键切片。搜索索引的规范化文本与简拼共用一个字符串，以保存的边界分别匹配，不能跨段命中；为 ASCII 和无大小写转换的名称一次预留全部容量。需要 Unicode 大小写转换时保留整串转换，避免破坏上下文相关映射。逐字符修改复用查询容量；查询不变不重筛，光标／选区不变不提交场景。退出搜索保留本轮查询与索引容量，退出 UIHint／重扫释放；字符捕获在退出及错误恢复时关闭。绘制场景仍有所有权分配，查询索引分配测试不能当作整次输入零分配的结论。

点位检查及其移动状态只在结果信息面板出现时按需创建，复用成员容量，面板隐藏后释放。普通标签事件跳过检查处理；信息面板和搜索框布局使用独立函数，普通标签绘制不进入面板的大型栈帧；信息面板中的单点及已确定多点均开启取色及刷新 timer；颜色 concat 复用成员样本缓存并串行异步采集，switch 仅采集当前检查点。普通标签、空搜索及没有可预览结果的搜索不调用原生采样。一次 Hint 事件完成过滤、检查状态和命中更新后只生成一份最终场景，关闭输入／确认移动先于恢复场景，场景先于采样、复制回调及生命周期切换。不要为了合并绘制改变这些命令顺序。

首次标签场景提交后主动预热搜索文本／拼音索引，不等用户搜索：复用零延时一次性 timer，每次最多处理 256 个目标，未完成时立即重排同一 timer，不增加等待或周期计时器。Engine 每轮只派发该轮到期 timer 的快照，因此下一份工作前会重新处理输入／原生事件；不是新线程，也不等待原生出像素确认。追加目标保留已建索引前缀，先提交标签再预热新增部分；实际删除目标才清空索引，未命中的撤销通知和重复目标保留已有索引。空搜索入口不强制完成索引，非空查询保留同步兜底并复用已准备前缀，避免漏掉尚未预热或迟到的目标。重扫／退出取消预热，迟到 timer 不恢复已结束会话。预热仍消耗 CPU 和保留内存，不能声称未搜索时零开销；固定控件类型的中文别名和简拼使用静态对照，只转换名称／OCR／辅助信息。

窗口移动／缩放按键只提交原生请求；几何确认前不重复生成旧边框和卡片，状态提示及显式目标选择仍立即重绘。确认结果驱动两端共用的场景生成，不能用预测位置冒充原生成功。macOS 覆盖层复用 Backend 的显示快照，显示变更或首次快照缺失时才枚举；枚举失败重新标记刷新，避免永久使用过期数据。

选中窗口卡片在现有应用名／Tab 组标题行加入勾选标记，复用原有卡片尺寸与标签槽位。可配置的选中底色与轮廓在 `WindowStyles` 中预编译；文字缓存包含逻辑组选中状态，几何变化仍复用文本，选择变化才失效，不新增逐帧字体或原生绘制对象。

窗口帮助的宽度由键位、模式标题和数字输入决定，窗口标题、设备名与操作结果只在现有状态行内省略显示，不驱动列数或整面板字体缩放。窗口、Quick、Editor、Tab 与恢复列表保留空的反馈行，结果出现或清除不伸缩面板；原有多选输入布局保持。Windows 仍复用现有完整帧绘制与场景去重，不增加脏矩形、图元缓存或新的表面。

窗口多选帮助的固定键位说明在进入输入时生成，随输入状态释放；逐键刷新只构造当前数量和光标文字。目标读取按逻辑窗口借用遍历，计数和布局生成不先收集完整身份列表；需要修改会话或逆序提交的请求仍先拥有目标身份。布局提交先检查编辑状态，只在 Quick 有待提交几何时读取操作目标，不在空闲、等待确认或 Tree 路径整理无用列表。

扫描会话的去重索引保存量化几何的紧凑哈希，碰撞链仍核对完整量化几何、名称和角色，不能把哈希相等当作目标相同。退休继续匹配原始矩形；首次批次和追加用同一 Entry 完成查找与写入，扫描完成／退出释放索引。

重叠层规划按连通组处理。若组内每个标签都与其余标签冲突，层数和前后顺序已由绘制顺序确定，直接赋层，跳过候选择色、压缩和评分。标签长度先由保留的 LabelPlan 与实际字符集推导，等长时复用估算宽度；流式追加、退休替换和搜索过滤不按当前可见数量重新推断。按行带保守证明互不相交的布局直接写入无叠层计划，不进入图工作区；等长批次中连续相同矩形的组若互相分离、组内实际遮挡成立，则直接写入各组层序。混合长度但共用左边、右边或中心对齐的密集标签，仍逐对确认全部遮挡关系后才直接赋层。这些路径不受 128／512 个标签门槛限制，不创建临时打包数组；其余图形仍使用原有候选算法。判定使用实际冲突关系，不假设相同位置或矩形相交就必然互相遮挡。图及着色工作区留在独立函数，避免首屏的已证明布局进入大型栈帧。

宽标签计划先检测是否存在冲突，再按需构图。检测复用扫线候选数组，按纵向包围范围保守排除候选；扫描线越过最早到期的横向区间后才清理候选。范围判定必须保守，保留不等高标签、浮点边界及无效几何的原有语义，不改变实际遮挡判定和最终层序。

搜索文字通过 OverlayLabel 的紧凑编辑位置描述光标／选区，原生后端使用实际字体宽度定位，公共层统一控制装饰高度与裁剪。DirectWrite 保留单个编辑布局，macOS 复用文本测量及光标层；隐藏／离开编辑场景释放相应缓存。macOS 固定面板文字按字体行高垂直居中，不复用普通标签的光学基线偏移。

原生槽位匹配共用 `platform/common/overlay_reconcile.rs`：编辑图层身份不含查询文字，过滤与输入更新时保持槽位稳定，公共测试在两端运行。macOS 文字变化在禁用动画事务中清除旧 contents 并标记重绘，由系统统一提交；输入线程不得逐图层调用 displayIfNeeded 强制同步绘图。CoreText 每段文字只排版一次，再读取 UTF-16 插入位置，避免逐前缀复制与重复测量；仅移动光标不重建文字。Windows 直接重画完整帧，不需要额外维护 CATextLayer 槽位。

共享搜索在会话内复用词项范围缓冲，每个词项在候选循环外解析标签标记，去重后按首次出现顺序扫描；只有多个不同词项才维护候选去重标记，单词查询跳过标记清零及读写；重复粘贴词不会反复遍历目标，单独的 @ 不扫描目标。退出 UIHint／重扫释放范围缓冲，退出搜索保持容量供下次复用。

搜索输入不在展示层按估算字宽提前截断，后端复用现有字形位置滚动和裁剪，短输入保持左对齐；输入与 Point 复用同一文字布局和固定基线，Point 隐藏光标并显示末尾。圆点与左侧文字使用对称内边距，多点计数并入同一次原生布局，按实际宽度右对齐并紧邻圆点，查询与计数只保留固定小间距，短查询不重复绘制内联后缀；原生布局变化时缓存计数宽度与文字区边界，后续帧不重复查询计数字形位置。信息栏使用完整列宽；不维护字体分类或增加独立测量缓存。

搜索匹配度和类别优先级在配置装配时编译为固定查表；过滤时按九个固定分组连接结果索引，每项仅保存一个后继索引，连续同组成员使用默认相邻后继，不进行比较排序。首项自动显示，point_next 以 O(1) 推进候选游标，不重新扫描文字、排序或生成候选字符串。文字匹配复用已归一化索引，首词直接判定完整匹配；布尔包含检查先排除未命中，再查看实际匹配位置的相邻字符判定完整词、词首和包含匹配。查询包含可转换汉字时在词项准备阶段排除不可能命中的简拼表示；字面文字已匹配时不重复搜索保留的拉丁字符简拼。循环顺序与显示标签顺序、完整标签编号空间、已解析多选集合分开，避免调整优先级改变重叠层与选中身份。查询和结果变动使顺序失效，退出搜索复用容量，重扫／退出会话释放缓存。

Hint 场景在绘制标签前计入搜索信息栏、色块和点位图元容量，避免追加小面板时扩容并复制整份标签／边框缓冲。

搜索候选只保存完整 search_hints 中的位置，显示标签在过滤时原位更新，身份和几何未变时跳过复制；不再维护第二份候选标签或逐查询清空后全量复制。手动预览独立保留 label／几何身份，原始索引因流式追加或退休变化后重新定位，不能依赖旧向量位置。
