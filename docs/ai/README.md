## 工作原则

- 优先响应速度，其次内存；用实际场景验证取舍。
- 遵守项目 `AGENTS.md` 的不变量。其余实现可依据源码、测试和测量调整，不把历史方案视为唯一解。
- 本目录只维护稳定职责、关键语义和查找入口；不追加版本流水、完整配置、逐次基准结果或代码逐行解释。
- 改变边界、生命周期或主要模块时更新相关专题及本索引；同一事实尽量只写一处。
